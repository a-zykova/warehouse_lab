# warehouse
# Лабораторная работа: Система управления складом (C++)

## Цель работы
Освоение принципов ООП, паттернов проектирования («Фабричный метод» и «Итератор»), а также реализация правила пяти (Rule of Five) на примере системы управления складом.

## Структура проекта
Код разбит на логические модули (каждый класс в отдельном файле `.h` и `.cpp`):
* **`attributes/`** — классы-атрибуты `Price`, `Quantity`, `Weight` с валидацией (не допускают отрицательных значений).
* **`products/`** — иерархия товаров:
  * Базовый абстрактный класс `Product` с чисто виртуальным методом `clone()`.
  * Промежуточные категории: `Electronics`, `Clothing`, `Food`.
  * Конкретные товары: `Smartphone`, `Laptop`, `TShirt`, `Jacket`, `Milk`, `Bread`.
* **`products/Warehouse.h/.cpp`** — класс склада с правилом пяти (глубокое копирование и перемещение) и собственным итератором.
* **`products/Factories.h/.cpp`** — паттерн «Фабричный метод» для создания товаров.
* **`oon1.cpp`** — главный файл с интерактивным меню (5 демонстрационных сценариев).

## Реализованные паттерны и принципы
1. **Фабричный метод:** Класс `ProductFactory` и 6 конкретных фабрик для создания товаров.
2. **Итератор:** Класс `WarehouseIterator` (и `ConstWarehouseIterator`) для обхода склада.
3. **Прототип (clone):** Используется для глубокого копирования товаров при копировании склада.
4. **Правило пяти:** Реализовано для класса `Warehouse` (конструктор копирования, оператор присваивания, конструктор перемещения, оператор перемещения, деструктор).

## Демонстрационные сценарии (Интерактивное меню)
При запуске программы появляется меню:
1. **Создание и вывод** — добавление товаров через фабрики и обход склада итератором.
2. **Копирование склада** — проверка глубокого копирования (изменения в копии не влияют на оригинал).
3. **Перемещение склада** — проверка семантики перемещения (старый склад становится пустым).
4. **Поиск и удаление** — поиск по ID, категории, цене; удаление по ID и индексу.
5. **transferTo** — перемещение товара между складами.

## Тестирование и обработка ошибок
* Реализована валидация атрибутов (цена, вес и количество не могут быть отрицательными).
* Обработан ввод некорректных данных с клавиатуры (защита от ввода букв вместо чисел).
* Настроена корректная работа с русским языком в консоли (UTF-8).

## Как собрать и запустить
1. Открыть решение `.sln` в Visual Studio.
2. Нажать **F5** (Локальный отладчик Windows).
3. Взаимодействовать с меню в консоли.
